# Lanthorn 1.0.0

The first release. Lanthorn is a local-first video player for Android, built on libmpv: no ads, no
tracking, no account. Android 10 and later, GPL-3.0-or-later.

## Which APK

| File | For |
|---|---|
| `lanthorn-1.0.0-arm64-v8a.apk` | Almost every phone from the last eight years. Pick this if unsure. |
| `lanthorn-1.0.0-armeabi-v7a.apk` | Older 32-bit phones. |
| `lanthorn-1.0.0-x86_64.apk` | Emulators and x86 devices. |
| `lanthorn-1.0.0-universal.apk` | Any device. Larger. |

Check a download against `SHA256SUMS`: `sha256sum -c SHA256SUMS --ignore-missing`.

## What it does

| Area | In 1.0.0 |
|---|---|
| Playback | Hardware decoding with automatic fallback to software, a decoder badge to switch, per-file and per-extension decoder choice. Info panel. Seek preview frames. Speed with pitch kept, A-B repeat, sleep timer, chapters, frame screenshot. Folder queue, loop, shuffle, smart previous. Clear reasons when a file will not play. |
| Background | Plays on with the screen off or from the notification, headset keys, audio focus, picture-in-picture. |
| Video | Fit, aspect ratios, zoom and pan, rotation, mirror and flip, night mode, brightness and contrast, deinterlacing. Lock and kids lock. |
| Gestures | Swipe to seek, brightness and volume; double tap to skip or pause; hold for fast play; pinch to zoom. Each one can be turned off. |
| Subtitles | Load by themselves (your language, a file beside the video, the default track). Encoding detection, right-to-left and complex scripts, ASS/SSA by libass. Delay, speed, style and placement with a live preview, subtitle gestures. Optional online search with your own OpenSubtitles account. |
| Audio | Track picker, audio delay, volume boost to 200 % with a limiter, 10-band equalizer, stereo modes. |
| Library | Folders or all videos, list or grid, lazy cached thumbnails, SD cards. Sort, search, scan control, hidden folders. New, in-progress and watched marks, resume last. Multi-select to play, share, rename, delete. Playlists. |
| Network | http, https, rtmp, HLS and DASH links with history and clear error reasons. SMB 2 and 3 shares, found on the network or added by address. |
| Settings | Searchable settings, light, dark and pure black themes, wallpaper colours, per-app language, backup and restore. |
| Privacy | No request you did not start, no analytics, telemetry or crash reporting. Media access only, explained first; selected-videos access on Android 14 and later. |

## Performance

Emulator, software decode, regressions only, no speed claim. Numbers from an Android 16 emulator
(x86_64, no GPU, no hardware video decoder) with short test clips. A phone's numbers will be very
different. The comparison on a real phone comes in a 1.0.x release.

| Measure | Target on a phone | Lanthorn | Another popular player |
|---|---|---|---|
| Cold start, p50 / p90 | 500 ms | 408 / 496 ms | 1405 / 1840 ms |
| First video frame, H.264 1080p60, p50 | 300 ms | 2774 ms | not measured here |
| Dropped frames, H.264 1080p60, 10 s | 0.1 % | 73.6 % | did not show a video on the emulator |
| 4K HEVC 10-bit and 4K AV1 | hardware decode | plays, software only here | not measured here |
| Seek release to target frame, p50 | 200 ms | 730 ms | not measured here |
| Preview frames per second while dragging | 10 | 1.5 | not measured here |
| Installed size | 35 MB APK (arm64) | 36.9 MB (x86_64 bench build); arm64 APK 31.8 MB | 109.5 MB |

## Known limits

Checked only on emulators so far, not yet on a range of phones:

- Timing bounds that need a real phone: the numbers above, and the 100 ms and one-frame bounds on
  speed, zoom, mirror and picture changes.
- A hardware decoder that stalls in the middle of a seek falls back to software on the emulator;
  on a real phone this is checked by hand.
- Pausing when headphones are unplugged, and the Bluetooth audio delay, need a real headset.
- External audio sync within 40 ms, and the volume-boost peak level, need a real audio output.
- SD card and USB mounts are unit-tested, not checked on hardware.

Not in this release: FTP, SFTP, WebDAV and USB drives; TTML and DFXP subtitles; audio passthrough
and fade-in; a first-run gesture guide, keyboard and D-pad control; undo for deletes.
